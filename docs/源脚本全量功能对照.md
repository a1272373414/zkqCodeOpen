### 0.2 生成方式

1. `tools/scan_lua_skeleton.py`：按缩进与 `end` 配对，切出全部**命名块**（`_ENV["X"] = function` / `function X(` / `local function` / 多行表），
   输出 行范围 + 嵌套层级 + 关键 API 调用计数 + 中文串样例 + 被调用函数 + 表内键名。
2. 按块**逐块核对源码**（分段 dump 阅读），写出一句话功能与关键细节（坐标 / 颜色特征 / 配置键 / 接口名）。
3. `tools/scan_lua_skeleton.py` 同时输出**未被任何命名块覆盖的顶层语句段**，这些段单独成行描述。
